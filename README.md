## 🎞️ Sobre o projeto

Este projeto foi desenvolvido como parte da **Atividade Aula 02 — Desenvolvendo uma Página Web**, com o objetivo de colocar em prática os conhecimentos adquiridos nas aulas de **HTML**.

A proposta consiste na criação de uma página web dedicada a um filme escolhido pela aluna, apresentando suas principais informações de maneira **organizada, clara e visualmente agradável**.

Para a construção da página foram utilizadas estruturas básicas do HTML, incluindo títulos, subtítulos, parágrafos, imagens e links no viscode.

---



## 🎯 Objetivo do projeto

O principal objetivo desta atividade é desenvolver uma página HTML utilizando corretamente as principais tags estudadas em aula.

Durante o desenvolvimento, foram praticados conceitos como:

* 🏷️ Estrutura básica de uma página HTML;
* 📝 Utilização de títulos e subtítulos;
* 📄 Organização de informações em parágrafos;
* 🖼️ Inserção de imagens;
* 🔗 Criação de links;
* 📁 Organização de arquivos e pastas;
* 💻 Estruturação de um projeto web.

## 🧩 Estrutura HTML utilizada

A página foi desenvolvida utilizando algumas das principais tags apresentadas durante a aula:

```html
<title></title>
```

Utilizada para definir o título da página exibido na aba do navegador.

```html
<h1></h1>
```

Utilizada para apresentar o título principal da página.

```html
<h2></h2>
```

Utilizada para organizar as informações do filme em subtítulos.

```html
<p></p>
```

Utilizada para apresentar a sinopse e outros textos.

```html
<img>
```

Utilizada para adicionar uma imagem relacionada ao filme.

```html
<a></a>
```

Utilizada para criar um link para uma página com mais informações sobre o filme.

---

## 🖥️ Sobre a página

A página desenvolvida apresenta informações essenciais sobre o filme escolhido, permitindo que o visitante conheça um pouco mais sobre a obra.

A organização da página foi pensada para deixar as informações **fáceis de localizar e compreender**, mantendo uma estrutura simples e adequada aos conhecimentos trabalhados na atividade.

### 📌 A página contém:

* 🎬 Nome do filme;
* 🖼️ Imagem relacionada à obra;
* 📅 Ano de produção;
* 🎥 Diretor;
* ⏱️ Duração;
* 🔞 Classificação indicativa;
* 🎭 Gênero;
* 🌎 País de origem;
* 📖 Sinopse;
* 🔗 Link para mais informações.

## 📁 Organização do projeto

### 📄 `index.html`

É o arquivo principal do projeto. Nele está localizada toda a estrutura HTML da página sobre o filme.

### 📁 `img`

Pasta destinada ao armazenamento das imagens utilizadas no projeto.

### 📄 `README.md`

Arquivo responsável por apresentar informações sobre o projeto, sua finalidade, tecnologias utilizadas e organização dos arquivos.
